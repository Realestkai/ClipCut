# Where the ClipCut sounds come from

Every file in `audio/` is CC0-1.0 (public domain dedication). Each row of
`manifest.json` names its own source page and author. The files are byte for
byte as their authors published them, only renamed; nothing was re-encoded,
trimmed or normalised.

The licence stated on each page was read on 2026-11-15.
